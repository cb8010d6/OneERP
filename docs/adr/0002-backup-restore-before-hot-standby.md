# ADR 0002: 数据保护先采用备份恢复，不做热备

日期 / Date: 2026-05-14

## 状态 / Status

Accepted

## 背景 / Context

OneERP 将承载真实库存和财务数据。当前最紧急的风险不是多机切换，而是确保数据能按明确流程备份、恢复、演练和回滚。

## 决策 / Decision

试生产阶段先采用备份恢复策略：

- PostgreSQL 默认每 15 分钟备份一次。
- MinIO 默认每 60 分钟备份一次。
- 每次重要上线前必须执行恢复演练。
- 恢复演练输出 `restore-drill-report.json`。
- 默认恢复目标为 RPO 15 分钟、RTO 1 小时。
- 不在本阶段引入 PostgreSQL 热备、Redis Sentinel 或跨机自动复制。

## 后果 / Consequences

收益：

- 降低上线复杂度。
- 备份和恢复责任清晰，适合小团队和小白部署。
- 可通过演练证明真实数据可恢复。

代价：

- 故障时会有最多 15 分钟数据风险。
- 恢复过程需要人工执行。
- Redis 暂不作为关键持久数据来源。

## 复核条件 / Revisit When

- RPO 15 分钟或 RTO 1 小时不再满足业务。
- MinIO 文件量增长到恢复时间不可接受。
- 客户要求自动故障切换或托管数据库。
